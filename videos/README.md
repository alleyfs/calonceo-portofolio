# Videography assets

Video bisa ditautkan dari platform yang sesuai atau disimpan lokal di folder ini jika file berukuran kecil dan memang dibutuhkan.

Untuk video lokal, tambahkan data pada array `videographyItems` di `../js/script.js` dengan `videoUrl: "videos/nama-video.mp4"`. Thumbnail yang dimiliki sendiri dapat ditempatkan di `images/videography/` (buat folder tersebut jika diperlukan). Video besar umumnya lebih cocok di-host di platform video agar repository tetap ringan.
