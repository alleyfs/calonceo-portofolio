# Image assets

Tambahkan aset gambar asli yang memang ingin dipublikasikan di website ini.

- Poster lomba: `poster-bijak-bermedsos.jpg` (file ini belum disertakan).
- Foto galeri: simpan di subfolder `photography/` lalu daftarkan di `photographyItems` pada `../js/script.js`.
- Thumbnail video: buat subfolder `videography/` jika dibutuhkan, lalu gunakan path relatif dalam array `videographyItems`.

Optimalkan gambar sebelum commit. Jangan gunakan gambar yang tidak memiliki hak untuk dipublikasikan. Nama file sebaiknya lowercase, tanpa spasi, dan menggunakan tanda hubung.
