# Photography gallery assets

Taruh foto karya asli di folder ini, lalu daftarkan masing-masing file ke array `photographyItems` pada `../../js/script.js`.

Contoh nama file: `suasana-sore-01.jpg` atau `detail-arsitektur-01.webp`.

Gunakan nama file lowercase dengan tanda hubung. Informasi perangkat, teknik, dan lokasi bersifat opsional; isi hanya jika informasinya benar. Foto tidak perlu dipotong ke rasio tetap oleh website.
